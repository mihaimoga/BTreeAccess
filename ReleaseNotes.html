History

  • 14th August, 2014 - Version 1.03 - Initial release
  • 1st April, 2023 - Same version - Moved source code to GitHub
  • Version 1.04 (June 25th, 2023):
    • Updated About dialog with GPLv3 notice;
    • Replaced old CHyperlinkStatic class with PJ Naughter's CHLinkCtrl library.
  • Version 1.05 (October 20th, 2023):
    • Updated the About dialog (email & website).
    • Added social media links: Twitter, LinkedIn, Facebook, and Instagram.
    • Added shortcuts to GitHub repository's Issues, Discussions, and Wiki.
  • Version 1.06 (January 20th, 2024):
    • Added ReleaseNotes.html and SoftwareContentRegister.html to GitHub repo;
    • Replaced old CFileDialogST class with Armen Hakobyan's CFolderDialog library;
    • Replaced NULL throughout the codebase with nullptr.
      Replaced BOOL throughout the codebase with bool.
      This means that the minimum requirement for the application is now Microsoft Visual C++ 2010.
  • Version 1.07 (November 17th, 2024):
    • Updated copyright information;
    • Updated the X (Twitter) profile link.
  • Version 1.08 (February 6th, 2025):
    • Updated GetModuleFileName calls to handle path length > _MAX_PATH.
  • Version 1.09 (November 26th, 2026):
    • Migrated the development environment to Microsoft Visual Studio 2026 (MSVC v145 toolset);
    • Resolved all compiler warnings at Debug level 4;
    • Fixed the version number format in the About dialog (1.08 instead of 1.8);
    • Added Doxygen and inline comments to the code;
    • Added README.md, SECURITY.md and AGENTS.md to GitHub repo;
    • Updated the project settings, the copyright information and the Bootstrap library;
    • Added the UnitTests project to the solution: unit tests (Microsoft Native Unit Test Framework) for CNetworkBase, CNetworkHash, CNetworkTree and CVersionInfo, and for the upload, download, delete and restart workflows of the main dialog;
    • In the tests, a message box or a failed assertion raised by the code under test fails the running test instead of blocking the run, so the tests can run unattended;
    • Updated README.md, AGENTS.md and this article to match the current code and to describe the unit tests.
  • Version 1.10 (TBD):
    • The unit tests now run during the build: a post-build event of the UnitTests project runs them with vstest.console.exe after every build, so a failing test fails the build and, in a solution build, the application is not built;
    • Updated README.md, AGENTS.md and the article (BTreeAccess.html) to describe how the tests run during the build.
